AmarShowsBook page and file map
Updated: 2026-06-27

Purpose
This guide explains where each user-facing page lives, which controller action serves it, and which supporting model or asset files are commonly involved. The project keeps ASP.NET MVC conventions: Controllers hold route logic, Views hold Razor markup, Models hold database/view models, Services hold reusable business checks, and wwwroot holds public CSS/JS/uploads.

Shared layout and global assets
- Views/Shared/_Layout.cshtml
  Main application shell, navbar, theme switcher, session popup, cinema popup, global scripts, and version badge.
- Views/Shared/_AdminLayout.cshtml
  Admin shell and admin theme switcher.
- wwwroot/css/site.css
  Public site-level CSS loaded after Bootstrap.
- wwwroot/js/site.js
  Public site-level JavaScript.
- wwwroot/uploads/
  User and developer uploaded images.

Authentication pages
- /Auth/Login
  Controller: Controllers/AuthController.cs
  View: Views/Auth/Login.cshtml
  Purpose: Login, password validation, theme-aware auth card.
- /Auth/Signup
  Controller: Controllers/AuthController.cs
  View: Views/Auth/Signup.cshtml
  Purpose: Register user and set default role.
- /Auth/ForgotPassword
  Controller: Controllers/AuthController.cs
  View: Views/Auth/ForgotPassword.cshtml
  Purpose: Start reset-password OTP flow.
- /Auth/SendOTP
  Controller: Controllers/AuthController.cs
  View after post: Views/Auth/VerifyOTP.cshtml
  Purpose: Sends reset OTP and shows dev OTP popup when configured.
- /Auth/VerifyOTP
  Controller: Controllers/AuthController.cs
  View: Views/Auth/VerifyOTP.cshtml
  Purpose: Validate reset OTP.
- /Auth/ResetPassword
  Controller: Controllers/AuthController.cs
  View: Views/Auth/ResetPassword.cshtml
  Purpose: Save new password.
